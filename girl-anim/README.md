# 모모 — 디즈니 12원칙으로 움직이는 소녀

디즈니 애니메이터의 12가지 원칙을 실제로 적용해 만든 인터랙티브 웹 데모입니다.
단일 `index.html` (외부 라이브러리 0개, 바닐라 SVG + JS)로 동작합니다.

**바로 보기 → https://kf9fcs9zjp-prog.github.io/girl-animation-demo/**

## 조작
- **점프 / 인사 / 빙글 / 반짝** 버튼, 또는 캐릭터를 직접 터치
- **0.35× 느리게** — 원칙이 눈에 보이도록 전체 동작을 느리게 재생
- 화면 위 캡션이 지금 어떤 원칙이 쓰이는지 실시간으로 알려 줍니다
- **12원칙 보기** — 12가지 원칙과 이 데모에서의 쓰임

## 적용한 원칙
| 원칙 | 어디에 |
|---|---|
| 예비동작 (Anticipation) | 점프 전 움츠리기, 팔을 들기 전 살짝 내리기, 빙글 전 반대로 틀기 |
| 찌그러짐 & 늘어남 (Squash & Stretch) | 도약 시 세로로 늘고 착지 시 납작하게 눌림 — 부피는 유지 |
| 호 궤적 (Arcs) | 팔·고개가 직선이 아닌 곡선으로, 손끝 자취가 화면에 찍힘 |
| 따라오기 (Follow Through / Overlapping) | 머리카락·리본·치마가 스프링으로 한 박자 늦게 정착 |
| 슬로우 인/아웃 | 모든 구간에 이징, 시작과 끝은 천천히 |
| 부수동작 (Secondary Action) | 손목 흔들기, 눈 깜빡임, 별 파티클, 어질어질 눈동자 |
| 타이밍 | 동작별 길이와 구간 비율 (예비 30~50%) |
| 과장 (Exaggeration) | 눌림·늘어남을 실제보다 크게 |

## 구조
- 캐릭터: 손으로 그린 SVG 파츠(머리카락·리본·치마·눈·입)를 JS가 매 프레임 변환
- 2차 동작: 머리카락/치마/리본마다 스프링(강성·감쇠)을 따로 두어 지연·오버슈트 생성
- 카메라: 점프로 화면을 벗어나지 않도록 자동으로 살짝 물러났다 돌아오는 프레이밍
- 참고: https://github.com/dylantarre/animation-principles
