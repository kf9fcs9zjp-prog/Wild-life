# 모모 3D — 리깅된 소녀로 움직이는 웹 데모

앞서 만든 2D SVG 데모를 **진짜 3D 캐릭터**로 올린 버전입니다.
무료로 추출한 3D 소녀 모델에 직접 관절(뼈대)을 심고, 애니메이션 6종을 구워 넣었습니다.

**바로 보기 → https://kf9fcs9zjp-prog.github.io/Wild-life/girl-anim/**

## 조작
- 하단 버튼: **대기 / 걷기 / 달리기 / 점프 / 인사 / 빙글**
- **0.35× 느리게** — 모든 동작을 느리게 재생해 관절 움직임을 눈으로 확인
- 화면 드래그로 회전, 두 손가락으로 확대/축소 (모바일 사파리 지원)
- `girl.glb` — 이 페이지가 쓰는 **리깅된 모델** 그대로 내려받기

## 리깅 방식
| 항목 | 내용 |
|---|---|
| 입력 | `girl_disney_3d_smooth.glb` — 정점 24,236 / 삼각면 40,000 / 스킨 없음 / A포즈 |
| 뼈대 | 19관절 휴머노이드: hips·spine·chest·neck·head + shoulder/upperarm/forearm/hand ×2 + thigh/shin/foot ×2 |
| 스키닝 | 관절 캡슐 거리장 가중치 → 해부학적 높이 윈도우 → 공간 kNN 스무딩 → 정점당 최대 4개 영향 |
| 애니메이션 | 코드로 베이크한 6개 클립 (30fps, glTF `animations`) |
| 의상 | 몸 실루엣을 실측해 절차 생성한 원피스·신발을 같은 스켈레톤에 스키닝 |
| 텍스처 | 원본 아틀라스의 미베이크(검은) 구멍을 하모닉 인페인팅으로 복원 |

## 파일
- `index.html` — three.js 뷰어 (GLTFLoader + OrbitControls, ES 모듈 CDN)
- `girl.glb` — 리깅·스키닝·애니메이션 포함 GLB

게임 본편(`index.html`, `assets/`)은 이 작업에서 건드리지 않았습니다.
